## 1. 사용자 인증 및 회원 관리 (User Authentication)

### 1.1 로그인 (`07 Login.jpg`)

- **인증 방식**: 학교 포털 계정과 비밀번호를 통한 로그인.
- **최초 로그인 분기**: 입력한 계정이 DB에 존재하지 않는 최초 로그인 사용자일 경우, 입력한 아이디를 지닌 채 **회원가입 화면으로 자동 이동**.
- **유효성 검증 예외 처리**:
  - 아이디 또는 비밀번호 오입력 시 입력 폼 하단에 빨간색 안내 문구 출력: `"아이디 또는 비밀번호가 올바르지 않습니다"`
- **UI 구성 요소**:
  - 좌측 배너: 서비스 핵심 가치 및 단계별 프로세스(01 포트폴리오 02 랭킹) 안내 정보성 뷰.
  - 우측 폼: 아이디 입력 폼, 비밀번호 입력 폼, 로그인 버튼, 회원가입 바로가기 링크(`아직 계정이 없나요? 회원가입 하기`).

### 1.2 회원가입 (`08 Sign Up.png`)

- **진입 조건**: 로그인 화면에서 포털 아이디/비밀번호로 SSO 인증 후 서버가 `firstLogin: true`를 반환한 경우에만 이 화면으로 자동 이동. portalId는 서버 임시 세션에 저장되어 있으므로 프론트엔드에서 별도로 전달할 필요 없음.
- **입력 필드** (`POST /api/auth/register` 바디 기준):
  - 이름
  - 학년 (드롭다운 또는 선택형 폼, 1~4학년)
  - 학번 (9자리 숫자 제한)
  - 개인 GitHub 프로필 링크 (`https://github.com/username`, 선택)
  - 사용자 유형 선택 토글 버튼: `Student 학생`, `Professor 교수`, `Admin 관리자` (단일 선택)
- **유효성 검증 및 예외 처리**:
  - **학번 중복**: 이미 사용 중인 학번일 경우 `"이미 사용 중인 학번입니다"` 출력.
  - **학번 형식**: 9자리 숫자가 아니면 `"학번은 9자리 숫자여야 합니다"` 출력.
  - **GitHub 링크 형식**: 올바른 형식이 아닐 경우 `"올바른 GitHub 링크 형식을 입력해주세요"` 출력.
- **내비게이션**: 폼 하단 `로그인으로 돌아가기` 버튼 클릭 시 로그인 화면으로 전환.

### 1.3 마이페이지 (`09 My Page.png`)

- **프로필 영역**:
  - 사용자의 이름, 권한(Student), 학번, 학년, 및 GitHub 링크 출력.
  - `프로필 수정` 버튼 배치.
- **포트폴리오 관리 영역**:
  - `내 포트폴리오` 탭 활성화 (내가 작성했거나 참여자로 지정된 포트폴리오 리스트 목록화).
  - 리스트 아이템 구성 요소: 공감 수(하트 아이콘 + 숫자), 프로젝트명, 참여자 수(ex: `참여자 4명`).
  - 각 아이템 우측에 `수정`, `삭제` 관리 버튼 배치. (삭제는 작성자 및 관리자만 가능)

### 1.4 프로필 수정 (`10 Profile Edit.png`)

- **수정 불가능 필드 (Read-Only)**: 아이디, 사용자 유형 (회원가입 시 고정 정보).
- **수정 가능 필드**: 이름, 학년, GitHub 링크
- **유효성 검증**:
  - 이름을 비웠을 경우: `"이름은 필수 입력 항목입니다"` 문구 출력 및 저장 제한.
  - GitHub 링크 포맷 오류 시: `"올바른 GitHub 링크 형식을 입력해주세요"` 문구 출력 및 저장 제한.
- **피드백 기능**: 수정 성공 시 화면 하단에 초록색 스낵바 토스트 알림 출력: `"프로필이 수정되었습니다"`.

## 2. 메인 대시보드 (Main Dashboard - `01 Main Dashboard.jpg`)

### 2.1 공통 헤더 네비게이션 바 (Navigation Bar)

- **로고**: 좌측 상단 `Gachon Bridge` 로고 클릭 시 메인 대시보드로 이동.
- **메뉴 링크**: `포트폴리오` (목록화면 이동), `랭킹` (랭킹화면 이동), `마이페이지` (마이페이지 이동).
- **유저 프로필 뷰**: 우측 상단 유저 이니셜 아이콘, 이름(`김진우`), `내 포트폴리오` 정보 레이블 제공. 클릭 시 마이페이지로 이동.

### 2.2 배너 슬라이더 (Top Dynamic Banner)

- **기능**: 이번 학기 1등, 지난 학기 1등, 전체 기간 1등 포트폴리오가 일정 시간 주기로 자동 롤링 인터벌 전환 (인디케이터 `1/3` 및 화살표 좌/우 수동 내비게이션 지원).
- **콘텐츠**: 등수 타이틀, 프로젝트명, 요약글, 작성자명, 사용 기술 스택, 공감 수, 프로젝트 썸네일 미리보기 프리뷰 영역.
- **상세 이동**: `포트폴리오 상세 보기` 버튼 클릭 시 해당 포트폴리오 상세 화면으로 이동.

### 2.3 섹션별 리스트 뷰

- **인기 포트폴리오**:
  - **정렬 조건**: 누적 공감 수(하트)가 가장 높은 상위 최대 3개 프로젝트 고정 노출.
  - **카드 구성**: 프로젝트 썸네일, 프로젝트명, 요약 영역, 사용 기술 스택, 공감 수.
- **최근 등록 포트폴리오**:
  - 최근 등록 시점 기준 최신순 정렬 리스트. 슬라이드 혹은 가로 스크롤 형태로 추가 탐색 가능.
  - 카드 구성: 프로젝트 제목, 참여자 정보, 기술 스택 태그.
  - 우측 상단 `포트폴리오 모두 보기 ->` 버튼 클릭 시 전체 포트폴리오 목록 화면으로 전환.

## 3. 포트폴리오 목록 및 탐색 (`03 Portfolio Board Management.jpg`)

### 3.1 필터링 및 리스트 뷰

- **카테고리 탭 필터**: 상단 칩(Chip) 버튼 형태로 `전체`, `졸업`, `P-프로젝트`, `자율` 선택 시 동적 리스트 필터링 처리.
- **리스트 아이템 구조**: 썸네일 이미지 (`IMG`), 프로젝트명 및 요약글, 카테고리 태그, 기술 스택 문자열, 공감 수(하트 + 숫자).
- **페이지네이션**: 하단에 이전/다음 화살표 및 페이지 번호(`1, 2, 3...`) 컨트롤러 제공.
- **액션 플로우**:
  - **단일 클릭 (Single Click)**: 해당 행 활성화 상태(블루 테두리 피드백)가 되며, **우측 퀵 프리뷰 패널**에 데이터 바인딩.
  - **더블 클릭 (Double Click)**: 해당 포트폴리오의 **상세 화면으로 화면 전환 이동**.
- **포트폴리오 작성 링크**: 우측 상단 `포트폴리오 작성` 주황색 버튼 클릭 시 생성 화면으로 이동.

### 3.2 우측 퀵 프리뷰 패널 (Quick Preview)

- 목록에서 단일 선택된 프로젝트의 정보를 한눈에 보여주는 서브 컴포넌트.
- **출력 데이터**: 대표 이미지 썸네일, 프로젝트명, 공감 수, 요약설명, 참여 인원 정보(`참여 인원 4명 · 개발 기간`), 기술 스택 칩 배지 리스트, `GitHub` 바로가기 버튼, `배포 링크` 바로가기 버튼.

## 4. 랭킹 시스템 (`04 Ranking Awards.jpg`)

### 4.1 상위 TOP 3 시각화 카드 영역

- **1위 (최우수 프로젝트)**: 가장 강조된 블루 컬러 테마 카드, 트로피/왕관 그래픽 배지, 작성자(팀)명, 공감 수, `상세 보기` 버튼.
- **2위 (우수 프로젝트)**: 실버 테마 카드, 순위 표식, 작성자(팀)명, 공감 수, `상세 보기` 버튼.
- **3위 (인기 프로젝트)**: 브론즈/골드 라인 테마 카드, 순위 표식, 작성자(팀)명, 공감 수, `상세 보기` 버튼.

### 4.2 전체 랭킹 테이블 뷰

- **컬럼 구성**: 순위(1, 2, 3위는 컬러 배지 처리), 프로젝트명, 작성자/팀, 기술 스택, 공감(하트+숫자), 이동(`상세` 버튼).
- **정렬 및 필터**: 우측 상단 기수/기간 선택 드롭다운 토글(`이번 학기`, `지난 학기`, `전체 기간`) 선택에 따라 랭킹 데이터 동적 갱신.

## 5. 포트폴리오 생성 및 수정 (`11 Portfolio Create.png`, `13 Portfolio Modify.png`)

- **필수 입력 필드 데이터 (Validation 필수)**:
  1. **프로젝트명**: 텍스트 입력 폼
  2. **프로젝트 요약** : 한 줄 설명 폼 (최대 300자)
  3. **대표 이미지**: 클릭 시 파일 업로드창 오픈 (`PNG/JPG/GIF/WEBP 5MB 이하`). 선택한 파일을 `POST /api/images/upload`로 서버에 업로드하고 반환된 `/image/uuid_파일명` URL을 `thumbnailUrl` 필드에 사용. (선택 필드)
  4. **프로젝트 카테고리**: 단일 선택형 세그먼트 버튼 (`졸업 프로젝트`, `P-프로젝트`, `자율 프로젝트`)
  5. **GitHub 링크** : URL 형식 검증
  6. **개발 기간**: 날짜 범위 선택 폼 (`YYYY.MM.DD ~ YYYY.MM.DD`)
  7. **참여자가 설정한 본인의 담당 역할**: 하단 참여자 관리 섹션 연동

### 5.2 마크다운 편집기 컴포넌트 (Markdown Editor)

- **UI 구조**: 좌/우 분할 레이아웃 (Split View).

- 각 참여자 카드 내부에 고유 이름과 해당 팀원의 구체적인 **담당 역할(예: Frontend, Backend, AI / Data)을 개별 입력 및 수정**할 수 있는 인풋 필드 폼 결합. 개별 삭제(`X`) 가능.

### 5.4 수정 모드 분기 (`13 Portfolio Modify.png`)

- 기존 등록된 포트폴리오의 `수정` 버튼을 통해 진입 시, 기저장된 모든 정보(기본 정보, 마크다운 본문 텍스트, 업로드된 이미지, 참여자 리스트 및 역할 정보)를 서버로부터 수신하여 입력 폼에 **자동 데이터 바인딩(Pre-filling)** 처리.
